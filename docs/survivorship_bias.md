# 固定样本与幸存者偏差说明

v0.1 使用 510300、510500、600519、601318、000001、600036、600900、600030、000858、
601166 共 10 个当前可识别的证券测试数据管道。研究者在 2026 年选定了这组证券，因此它不是
2018 年当时可获得的历史股票池，也不能代表同期全部 A 股。

这组数据只能回答以下工程问题：

- 两类证券、10 个固定成员能否稳定取数、标准化和保存；
- 数据日期、价格关系、成交量单位和来源记录能否通过质量门禁；
- 同一次输入重复运行时，系统能否复用相同快照。

它不能支持横截面选股、全市场收益比较、策略有效性或可交易性结论。即使后续回测出现正收益，研究报告也必须继续披露以下限制：

- 样本由当前仍可识别的证券构成，存在事后选择和幸存者偏差；
- v0.1 没有历史成分股、历史 ST 状态、退市整理期或板块状态数据；
- 免费数据源可能回写历史行情，`research_approx` 只能保证冻结快照后的复现；
- 样本规模太小，无法估计策略在全市场的稳定性。

历史股票池和时点状态数据通过独立验收前，程序应拒绝扩大研究结论，也不能把固定样本称为“市场代表样本”。
