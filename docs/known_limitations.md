# v0.1-research 已知限制

## 样本与数据

- 10 个标的是固定工程试点，不是历史成分股，也不代表整个 A 股市场；仍有幸存者偏差和选择偏差。
- AKShare 和免费上游可能回写历史。发布夹具用 SHA-256 固定了本次输入，但不能证明上游未来仍
  返回相同历史版本。
- 指标价属于 `research_approx`。没有可验证的历史调整因子时点快照，因此不能称为严格时点安全
  复权。
- 当前公司行为证据只完整支持现金红利。送转、拆并股、配股和证券变更会关闭运行。

## 回测与成交

- 日线 OHLC 不能证明开盘瞬间的盘口、排队顺序和可成交量。开盘处于涨跌停价时保守拒单，只是
  避免伪造成交，不代表还原真实成交。
- 未建模滑点、部分成交、成交量上限、盘口冲击、券商通道延迟和真实结算差异。
- 费用使用显式研究假设；个人实际佣金、税收身份和券商收费可能不同。
- 20 个正式基准是独立单标的账户，不是共享现金组合。不能把单票净值相加后称为组合表现。

## 研究结论

- SMA 候选只用于验证冻结研究流程。保留期存在亏损，不能把局部正收益解释为已验证 Alpha。
- 100 行“10 日操作流程回放”只验证数据、信号、订单、拒单和日志链路，不是实盘或长期前向验证。
- 当前没有券商连接、自动下单、持续运行监控和已验证盈利策略。

## 完整性边界

- Git 提交、标签和本地 SHA-256 能发现意外损坏、文件混用和实现漂移，但不是第三方数字签名。
- 如果攻击者能够同时改写仓库、标签、冻结输入和预期清单，内部一致性检查不能证明外部真实性。
- 首次依赖安装在空缓存机器上可能访问 Python 包索引；只有安装完成后的研究重算承诺离线。
