# 风险指标口径

风险报告只读取已经完成且逐文件 SHA-256 验真的正式回测包。读取后再次验证
`cash + market_value + receivable = equity`，再从日频流水重算指标。报告不能读取裸 DataFrame，
也不能用 run.json 中预填的指标代替复算。

## 固定定义

| 指标 | 定义 |
|---|---|
| 总收益 | `末日净值 / 首日净值 - 1` |
| 年化收益 | `(末日净值 / 首日净值) ** (252 / 官方交易日区间数) - 1` |
| 年化波动 | 日简单收益的样本标准差（`ddof=1`）乘 `sqrt(252)` |
| Sharpe | 日简单收益均值除日收益样本标准差，再乘 `sqrt(252)`；无风险利率固定为 0 |
| 最大回撤 | 每日净值相对当时历史峰值的最大跌幅 |
| Calmar | 年化收益除最大回撤；最大回撤为 0 时记为 `N/A` |
| 累计毛换手 | 全部成交金额绝对值之和除全期平均日净值 |
| 年化毛换手 | 累计毛换手乘 `252 / 官方交易日区间数` |
| 最大敞口 | 每日持仓市值除当日净值的最大值 |

日收益不足两个时，样本波动率和 Sharpe 记为 `N/A`，不伪造为 0。零波动时 Sharpe 也记为
`N/A`。所有指标定义、风险阈值、20 个 run ID、universe ID 和实现指纹共同进入 report ID。
每个源包的 `artifact_manifest.json` SHA-256 也进入 report ID，报告因此固定它实际读取的
包版本；同一哈希会显示在 Markdown 的“源回测包验真清单”中，便于人工抽查。

已发布报告可反向核对当前源包：

```bash
uv run aquant-report verify \
  --project-root . \
  --report-id <报告 ID>
```

该命令先验证报告自身的文件集合、artifact manifest、SHA-256 和 report ID，再按报告列出的
run ID 重新打开全部源回测包、复算指标并重建报告。只有重建后的 JSON 和 Markdown 与已发布
版本逐字节一致时才返回 `status="verified"`。

正式回测缺 bar 的官方交易日按停牌持有处理，向收益序列加入 0 收益区间并计入年化分母。
系统不填造 OHLC；这一补齐只用于时间权重，不产生订单、成交或价格。

## 当前风险阈值

- 最大回撤：50%；
- 最大敞口：100%。

超过阈值只标记 `risk_limit_breach`，不删除结果。总收益为负且未越限时标记
`strategy_loss`。正收益标记 `observed_positive_return_not_validated_alpha`，明确表示它只是冻结
历史样本中的观测值，不是策略有效性结论。

## 当前边界

报告中的 20 个运行是 10 次独立单标的 × 2 个基准，不是共享现金组合，因此没有“组合敞口”
或“组合最大回撤”。在多资产组合层实现前，不能把单标的指标加总成组合指标。

当前费用已含版本化佣金、最低佣金、印花税和过户费，但未建模滑点、成交量约束、部分成交、
个人红利税和现金利息。高换手策略即使在报告中盈利，也可能因这些缺失成本而被高估。

SHA-256 和内容寻址用于发现误损坏、静默覆盖和版本混用，不是数字签名。如果本地攻击者能同时
重写 CSV、artifact manifest 和报告，他仍可伪造一套内部自洽文件。审计结论依赖项目目录和
代码执行环境可信；强对抗场景需要外部只读存储、签名或第三方时间戳。任何争议结果都应从冻结
输入和提交重新运行，而不是只信本地文件。
