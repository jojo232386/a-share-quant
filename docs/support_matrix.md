# v0.1-research 支持矩阵

状态只使用四类：

- **支持**：有明确代码、测试和正式冻结重建证据；
- **保守近似**：日线或免费源无法证明全部真实细节，采用偏保守假设；
- **拒绝**：识别后关闭运行，不套用其他规则；
- **未实现**：当前没有这项能力，不能从相邻能力类推。

| 能力 | 状态 | v0.1 行为 |
| --- | --- | --- |
| 8 只固定沪深主板普通股票 | 支持 | 000001、000858、600030、600036、600519、600900、601166、601318 |
| 2 只境内股票型宽基 ETF | 支持 | 510300、510500，均按 T+1 |
| 日线不复权原始成交价 | 支持 | 成交、现金和持仓市值只用验真原始价 |
| 研究近似指标价 | 保守近似 | 只用于指标，披露免费源历史回写风险 |
| 收盘信号、下一官方交易日开盘尝试成交 | 支持 | 未启用 cheat-on-open/close |
| T+1、100 股/份整手、零股一次清仓 | 支持 | 按买入批次记录可卖日期 |
| 版本化印花税、过户费、佣金和最低佣金 | 支持 | 按成交日查最近生效费率，运行包记录触达费率 |
| 停牌 | 保守近似 | 目标交易日缺 bar 即 `suspended_no_bar`，不顺延成交 |
| 开盘处于涨跌停价 | 保守近似 | 日线不能证明排队，完整拒单 |
| 开盘未封板、盘中触板 | 保守近似 | 不因盘中触板拒绝，不能证明盘中流动性 |
| 现金红利 | 支持 | 除权参考价与应收/到账会计进入审计包 |
| 送转、拆并股、配股、证券变更 | 拒绝 | 公司行为快照出现即关闭运行 |
| 创业板、科创板、北交所 | 拒绝 | 不套用主板规则 |
| ST、历史状态不明、新股特殊阶段、退市整理 | 拒绝 | 缺少时点状态证据时关闭运行 |
| 债券、黄金、商品、跨境、货币 ETF | 拒绝 | 不从股票型 ETF 能力外推 |
| 部分成交 | 未实现 | 当前只有完整成交或完整拒单 |
| 滑点、成交量约束、盘口排队 | 未实现 | 日线不能支持真实撮合结论 |
| 共享现金多标的组合 | 未实现 | 当前是独立单标的运行集合 |
| 前向模拟守护进程 | 未实现 | 第 6 周不自动生成每日订单 |
| 券商连接、真实下单、自动交易 | 未实现 | v0.1 明确排除 |
| 盈利策略证明 | 未实现 | 现有负结果保留，不作收益承诺 |
