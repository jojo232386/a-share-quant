# A 股 v0.1 模拟执行规则

## 适用范围

本规则只用于研究与模拟。当前支持：

- 000001、000858、600030、600036、600519、600900、601166、601318 八只普通沪深主板股票；
- 510300、510500 两只境内股票型宽基 ETF；
- 日线、收盘后信号、下一官方交易日开盘尝试成交；
- 一次性完整成交或完整拒单。

当前不支持 ST、退市整理、新股特殊阶段、创业板、科创板、北交所、债券 ETF、黄金 ETF、盘中撮合、排队、成交量限制、部分成交、滑点和券商实盘。缺少足够规则证据时关闭运行，不用宽松假设补齐。

## 交易日与停牌

交易日历独立保存于 `data/calendars/`，使用内容寻址 ID 和 SHA-256 验真。正式回测必须显式传入 `--calendar-id`，日历更新不会改变既有行情快照的身份。

订单只在信号日的下一官方交易日尝试一次。目标交易日没有该证券的 K 线时，拒单原因为 `suspended_no_bar`，不得顺延到复牌日成交。日历覆盖不足时也拒绝运行。

## 信号与成交时序

策略在当日收盘后计算信号。市价单最早只能在下一官方交易日开盘尝试成交。没有启用 `cheat_on_open` 或 `cheat_on_close`。

规则判断位于 Backtrader 实际市价单执行入口之前；通过规则后，Backtrader 使用同一个开盘价和同一份已计算费用更新现金与持仓。

## T+1 与股数

八只主板股票和 510300、510500 均执行 T+1：

- 买入形成的份额在下一官方交易日才可卖；
- 标的停牌不推迟份额可卖日期；
- 买入数量必须是 100 股/份的整数倍；
- 卖出通常为 100 股/份的整数倍；
- 持仓含零股时，只允许一次性卖出全部剩余持仓，不能拆分零股。

系统分别记录总持仓、可用持仓、冻结持仓和每个买入批次的可卖日期。

## 涨跌停

v0.1 对八只普通主板股票和两只股票型宽基 ETF 使用 10% 涨跌幅：

- 股票价格步长为 0.01 元；
- 510300、510500 价格步长为 0.001 元；
- 涨跌停价由前收盘价计算并按对应步长四舍五入；
- 买单开盘价大于等于涨停价时拒绝；
- 卖单开盘价小于等于跌停价时拒绝。

日线 OHLC 无法证明开盘封板时是否能排队成交，因此使用保守拒单。若开盘未到限制价、盘中才触及限制价，v0.1 不因盘中触板拒单。拒单原因为 `price_limit_open`。

## 费用

所有金额先用 `Decimal` 计算，每个费用分项按四舍五入计到整数分，再汇总：

| 费用 | 适用范围 | 生效日 → 费率 |
| --- | --- | --- |
| 股票卖出印花税 | 普通主板股票卖出 | 2008-09-19 → 0.001；2023-08-28 → 0.0005 |
| 股票过户费 | 普通主板股票买入和卖出 | 2015-08-01 → 0.00002；2022-04-29 → 0.00001 |
| 股票佣金假设 | 普通主板股票买入和卖出 | 默认费率 0.00025，单笔最低 5 元 |
| ETF 佣金假设 | 510300、510500 买入和卖出 | 默认费率 0.00025，单笔最低 5 元 |

生效日查找规则是“成交日期小于等于生效日列表中的最新日期”。跨费率时期的回测会在 `run.json` 中记录本次实际触达的全部费率。

510300、510500 不收股票印花税和股票过户费。佣金属于研究假设，不代表用户真实券商费率，因此正式命令必须显式填写股票和 ETF 的费率及最低佣金。

## 现金、审计与拒单

买入前使用成交金额和全部费用检查现金，现金不足时拒单，不允许负现金。每个运行包包含：

- `run.json`
- `orders.csv`
- `fills.csv`
- `positions.csv`
- `cash.csv`
- `equity.csv`
- `lots.csv`
- `missing_sessions.json`
- `artifact_manifest.json`

`artifact_manifest.json` 对前八个载荷文件保存 SHA-256。导出采用整包原子发布；已有同名运行目录或冲突文件时拒绝覆盖。

运行 ID 绑定行情快照、交易日历、费用政策、证券类型、策略配置、Backtrader 版本和本项目执行实现源码指纹。每笔拒单保存机器可读原因。

## 结论边界

这些规则只让日线模拟更保守、更可审计。它们不能证明真实排队成交、盘中流动性、滑点、券商结算或策略盈利能力。真实数据上的成交笔数只是工程链路证据，不是收益证据。
