# 价格与复权政策

## v0.1：`research_approx`

`research_approx` 是 v0.1 默认且唯一允许的模式；配置仍须显式写入 `mode: research_approx`，加载器不对缺失字段隐式回填。配置还必须把 `adjust` 显式写成空字符串 `""`，数据入口据此请求原始不复权价格。

研究者可以冻结一次数据快照并记录依赖版本。同一快照内的结果可以复现，但上游数据可能在事后修订，快照也无法证明每条记录在历史当时已经可知。因此，v0.1 不具备严格的时点有效性。

核心回测把价格拆为三条明确的流：

- 原始不复权 OHLC：只用于成交、持仓估值、现金和费用；
- `indicator_close`：根据已验证的公司行为逐日因果生成，只用于 SMA 等指标；
- `reference_price`：非除权日等于上一交易日原始收盘，现金除息日等于上一原始收盘减每股/每份现金红利，只用于涨跌停规则。

前复权价格（`qfq`）不得进入核心回测，也不能充当成交或会计价格。正式回测还必须提供独立的公司行为 snapshot ID。现金分红在除息日开盘前登记应收款，在派息日转入现金；个人持有期限相关红利税未建模，当前固定披露为 `gross_before_personal_tax`。现金和应收红利均不计利息。

送股、转增、拆股、配股等非现金公司行为尚未支持；快照中一旦出现便关闭正式运行。派息日在回测区间内却没有可审计日线时也关闭运行，不把现金流擅自顺延到复牌日。

## v0.2：`strict_point_in_time`

`strict_point_in_time` 计划在 v0.2 处理。该模式需要按历史可知时间保存行情版本、公司行动及其公告或生效时间，并让回测按 `as-of` 时间读取数据。任务 1 没有实现这些能力，配置加载器会拒绝该模式。
